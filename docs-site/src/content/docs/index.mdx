## A verification engine, not a linter

Invariant parses a data contract, translates a real Spark job's logical plan into an
engine-independent representation, and checks the two against each other — structurally,
before Spark ever executes the write. A violation aborts the job. No output file is created.

<CardGrid stagger>
	<Card title="Real Spark execution" icon="approve-check">
		Verification runs against Spark's actual Catalyst logical plan — not a mock, not a static
		description of a table.

	<Card title="Enforcement, not just reporting" icon="warning">
