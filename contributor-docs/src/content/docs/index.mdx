## Not the user docs

This site is for **contributors to Invaract's own codebase** — project status, architecture
decisions, and per-module design docs. If you're looking for how to *use* Invaract (writing a
contract, installing the enforcement rule, running the demo harness), that's the
[user documentation site](https://mlltx.github.io/Invaract/) instead.

Every page here is generated straight from the same Markdown files contributors already read in
the repository (`ROADMAP.md`, `ARCHITECTURE.md`, `docs/**`) — this site only changes how they're
*read*, not what they say. Edit the source file, not a page here.
